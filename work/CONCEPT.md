# Концепция сцены «Как ЦОД отдаёт тепло»

Размер по Anatomy: **Hero** (80–150 узлов, с трубопроводами и деталировкой стоек деталей заметно больше).

## Объект и смысл движения

Инженерный макет на массивном основании. Слева на фальшполе три серверные стойки, в центре открытый шкаф
прецизионного кондиционера (исполнение по принципу Liebert HPM F, выбрано условно), справа за краем фальшпола
на улице — горизонтальный драйкулер с двумя осевыми вентиляторами и линейный насос на линии подачи.

Одна фраза: воздух зала по замкнутому кругу носит тепло серверов в кондиционер; там теплообменник фрикулинга
и/или холодильный контур перекладывают его в водно-гликолевую смесь; насос гонит смесь в драйкулер, где
наружный воздух, протянутый вентиляторами через оребрение, уносит тепло в атмосферу.

## Мир и камера

- 1 единица ≈ 2 см. x — вдоль макета (зал → улица), y — к зрителю, z — вверх.
- Азимут ≈ 58°: главная видимая грань +y (открытый разрез кондиционера), +x видна как боковая.
- Возвышение 30°.

## Группы деталей

**Основание (stand.)**: плита-основание с фаской, 8 опор с фланцами, паз по периметру, винты по углам, линейка,
гравированная табличка, бетонная площадка улицы со швами.

**Фальшпол (floor.)**: настил из плит 30×30 со швами, ряд плит у фасада снят (открытый срез подпольного
пространства), стойки-пьедесталы (пята, стержень, оголовок), стрингеры, три перфорированные плиты перед стойками,
торцевая кромка настила.

**Стойки (rack.)**: 3 шкафа 30×60×100: цоколь с регулируемыми ножками, рама (4 стойки), крыша, боковины,
монтажные профили с отверстиями; в каждом 8 серверных корпусов: лицевая панель, закрытые вентиляционные
прорези, ушки с винтами, индикаторы.

**Кондиционер (crac.)**: опорная рама в подполье (ножки, рама), шкаф: каркас, задняя и боковые панели,
крыша с решёткой возврата, фильтр с гофрой на направляющих, теплообменник фрикулинга (оребрение, трубные доски,
калачи, коллекторы), испаритель (оребрение, распределитель), палуба вентилятора, радиальный вентилятор
(входной коллектор, рабочее колесо с лопатками, двигатель, кронштейн), компрессор (кожух, купол, лапы, виброопоры,
патрубки), пластинчатый конденсатор (пакет, плиты, шпильки, 4 патрубка), расширительный клапан, соленоидный
клапан (13), двухходовой регулирующий клапан с приводом (12), коллекторы подачи и возврата, контроллер с
дисплеем, кабель.

**Гликолевый контур (glycol.)**: подающая и обратная трубы с фланцами, опоры с ложементами и хомутами, линейный
насос (корпус-улитка, фланцы входа и выхода, фонарь, двигатель с рёбрами, клеммная коробка, лапа на плите).

**Драйкулер (dry.)**: 4 ножки с пятами, рама, теплообменник с оребрением (закрытые прорези), боковые панели,
коллекторы входа и выхода с патрубками и фланцами, 2 осевых вентилятора: диффузоры-кожухи, лопасти
(вращаются в плоскости ротора), ступица, двигатель, защитные решётки, электрический короб.

## Маршруты потоков

1. **Воздух зала** (три параллельные петли, по одной на стойку): нижняя часть шкафа кондиционера → подполье
   (видно в открытом срезе) → перфорированная плита → лицевые панели серверов (вход) → сзади стойки (выход) →
   вверх за стойками → над стойками к решётке возврата на крыше кондиционера → фильтр → теплообменник
   фрикулинга → испаритель → вентилятор → вниз в подполье. Цвет: охра (тёплый) → голубой (холодный).
2. **Водно-гликолевая смесь**: драйкулер (выход, холодная) → насос → подающая труба → коллектор подачи в
   кондиционере → параллельно: клапан 12 → теплообменник фрикулинга, клапан 13 → пластинчатый конденсатор →
   коллектор возврата → обратная труба → драйкулер (вход, тёплая). Маркеры идут внутри труб.
3. **Хладагент** (нейтральные кольца): компрессор → нагнетание → конденсатор → жидкостная линия →
   расширительный клапан → испаритель → всасывание → компрессор. Скорость ∝ Q_DX, при полном фрикулинге стоп.
4. **Наружный воздух** только через драйкулер: снизу между ножками → через оребрение → вверх через вентиляторы.

## Модель

Все числа и скорости из `model.mjs` (учебные коэффициенты из задания). Плавно меняются только входы
(температура улицы и нагрузка); показания и анимация каждый кадр пересчитываются из одного состояния.

## 3D-вид, разборка и воздух

- **Геометрия одна.** `export3d.mjs` берёт формы деталей из рекордера аудита (призмы, тела вращения, трубы,
  шары) и переносит линии и винты SVG-рисунка на поверхности деталей лучом камеры. `scene3d.js` строит из
  этого меши в браузере: тона кита по нормали со светом, привязанным к камере, контуры и рёбра считаются
  на GPU. В исходном ракурсе (азимут 58°, наклон 30°) 3D-вид совпадает с изометрией: клик по детали
  выбирает тот же узел, что и в SVG.
- **Разборка** по правилам сборочного чертежа: серверы выдвигаются вперёд, крыши и фильтр вверх,
  теплообменники и вентилятор кондиционера вперёд, боковины и задняя стенка в стороны, двигатель насоса и
  вентиляторы драйкулера вверх; рамы, опоры и трубопровод на месте. Узлы уходят по очереди, сборка в
  обратном порядке. `node build.mjs --explode` прогоняет 516 кадров (вся установка и узлы шагов, туда и
  обратно) через проверку проникновений кита: 0 пар.
- **Воздух** без частиц: объём трубок вдоль линий тока с полосами шума, бегущими со скоростью потока;
  перекрытие деталями — по буферу глубины сцены. Без WebGL остаётся SVG-рисунок с маркерами.
- **Цвет воздуха по температуре.** У каждой точки линии тока своя температура из модели (uTs подача, uTr
  возврат, uTb между рядами, uTo улица, uTe за драйкулером); шейдер берёт цвет по шкале −8 / 21 / 26 / 31 /
  46 °C (тёмно-синий, голубой, песочный, янтарный, оранжевый). Волны с пологим тылом и резким фронтом бегут по
  потоку; ядро трубки бледнее края, сторона к свету светлее. Рёбра теплообменников, фильтр, крыльчатка и
  теплообменник драйкулера пишут в буфер глубины флаг «проницаемо»: поток за ними виден на 55 % в пределах
  34 единиц глубины, сплошные панели закрывают его полностью.
- **Путь горячего воздуха:** из задних панелей стоек в колпак горячего коридора, по верхнему каналу в
  переходный короб на крыше кондиционера, вниз через фильтр, ряды фрикулинга и испарителя, вентилятором в
  подполье, через перфоплиты холодного коридора к лицевым панелям.
- **Режимы в движении:** скорость хладагента и веток смеси, обороты вентиляторов драйкулера (доля UA),
  место охлаждения воздуха в теплообменнике, лампы контроллера (фрикулинг, компрессор, насос) и полосы на его
  экране, светодиоды активности серверов (частота по нагрузке).
- **Полный экран:** раскладка с рисунком и панелью уходит во весь экран через Fullscreen API, при отказе
  остаётся фиксированной поверх страницы. Кадр рисунка W×H вписывается в холст любой пропорции: поле
  добавляется поровну по краям, камера и воздух получают тот же кадр.
